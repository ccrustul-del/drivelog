# DriveLog — спидометр и трекер поездок

Статическое PWA без сборщика и собственного сервера. Поездки хранятся в IndexedDB, машины и настройки — в localStorage. Основные функции доступны офлайн после первой загрузки файлов.

## Запуск

Откройте каталог через любой статический хостинг с HTTPS (например, GitHub Pages) либо локально через `http://localhost`. Для геолокации, Service Worker, установки PWA и Wake Lock нужен защищённый контекст: HTTPS или localhost. Открытие `index.html` через `file://` не поддерживает эти возможности. Первый запуск должен пройти онлайн, чтобы браузер закэшировал приложение и загрузил Firebase SDK при настройке синхронизации.

На iPhone откройте сайт в Safari, нажмите «Поделиться» → «На экран Домой». Для записи поездки разрешите доступ к геопозиции; iOS может приостанавливать работу сайта, если свернуть браузер или заблокировать устройство. Уведомления показываются только при открытом приложении, если поддержаны установленной версией iOS/Safari. Фоновая доставка уведомлений без сервера невозможна.

## Возможности

- Запись GPS-трека, сглаженная скорость, дистанция, максимум, средняя скорость, топливо и эко-оценка.
- Онлайн-карта OpenStreetMap показывает текущее положение и маршрут, а в истории подгоняет карту под весь трек. Тайлы запрашиваются только для видимой области; отображается атрибуция OpenStreetMap. Для картографической подложки требуется интернет: стандартные тайлы OSM нельзя заранее скачивать для offline-режима.
- Автосохранение текущей поездки каждые 10 секунд и восстановление незавершённой записи при следующем запуске.
- История с фильтром, деталями, сравнением и экспортом трека в GPX.
- Несколько машин, редактирование, расчёт топлива и напоминания о пробеге ТО.
- Экспорт и импорт полного JSON-резервного файла.
- HUD с зеркальным режимом (нажмите на показание скорости, чтобы переключить отражение).
- Необязательная синхронизация Firestore с локальной персистентностью.

## Firebase (необязательно)

Создайте проект Firebase, включите Cloud Firestore и скопируйте web-конфигурацию из настроек приложения в экран «Firebase». Требуются `apiKey`, `projectId` и остальные поля конфигурации SDK. Настройте правила Firestore под свой сценарий доступа: приложение пишет документы в коллекции `trips` и `vehicles`, используя локальные ID как ID документа. Для реального использования ограничьте доступ аутентифицированным пользователем и отделяйте документы разных пользователей правилами/путями. Конфигурация хранится только в localStorage этого браузера; после сохранения приложение перезагружается.

## Хранение

Данные находятся на устройстве и очищаются вместе с данными сайта. Используйте экспорт JSON для резервной копии. Firebase — опциональное облачное хранилище, которое требует интернет-соединения и настроенных правил.
